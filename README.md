# COSMA Solution Website

Premium enterprise technology website for **COSMA Solution Co., Ltd.**

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS 4
- Motion + GSAP (Hero) + Lenis
- Lucide Icons

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Routes

- `/` — Home (full MVP experience)
- `/solutions` — Solutions scaffold
- `/industries` — Industries scaffold
- `/technology` — Technology scaffold
- `/insights` — Insights scaffold
- `/company` — Company
- `/contact` — Contact + consultation form
